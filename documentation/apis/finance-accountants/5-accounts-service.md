#  API: Accountant Service (`api_accountant_service`)

## **وصف الخدمة**
خدمة المحاسبة مسؤولة عن إدارة الحسابات المالية داخل النظام، مثل الأصول، الخصوم، الإيرادات، المصروفات، وحقوق الملكية. تقوم هذه الخدمة بتسجيل الحسابات وربطها بقيود اليومية والمعاملات المالية، مما يتيح تتبع التدفقات المالية بدقة.

## **الهدف من الخدمة**
- تسجيل الحسابات المالية داخل النظام وفقًا لمعايير المحاسبة.
- تصنيف الحسابات وفقًا للنوع (أصول، خصوم، إيرادات، مصروفات، حقوق ملكية).
- توفير واجهة لاسترجاع الحسابات وإدارتها.
- دعم التكامل مع الخدمات الأخرى مثل الفواتير والمعاملات المالية.

---

## **1. إنشاء حساب مالي جديد**

</div><div dir="ltr">

### **Endpoint Details**
- **URL**: `/api/accountant/accounts`
- **Method**: `POST`
- **Auth Required**: ✅ نعم
- **Permissions Required**: `create_account`

</div><div dir="rtl">

### **وصف العملية**
يُستخدم هذا الـ API لإنشاء حساب مالي جديد داخل النظام. كل حساب يجب أن يكون له رمز فريد يميزه ويحدد موقعه في شجرة الحسابات.

### **البيانات المطلوبة (`Request Body`)**
</div><div dir="ltr">

```json
{
  "account_name": "البنك الرئيسي",
  "account_code": "1001",
  "account_type": "Asset", 
  "currency": "SAR",
  "parent_account": "NULL",
  "description": "حساب البنك الرئيسي الخاص بالشركة",
  "is_active": true
}
```

</div><div dir="rtl">

### **توضيح البيانات**
- `account_name`: اسم الحساب (مثل: البنك الرئيسي، الموردين، العملاء).
- `account_code`: كود الحساب (يجب أن يكون فريدًا).
- `account_type`: نوع الحساب، ويشمل:
  - `Asset` (أصول)
  - `Liability` (خصوم)
  - `Equity` (حقوق ملكية)
  - `Revenue` (إيرادات)
  - `Expense` (مصروفات)
- `currency`: العملة المستخدمة في الحساب (مثل: SAR، USD، EUR).
- `parent_account`: الحساب الرئيسي الذي يتفرع منه هذا الحساب (يُستخدم في الحسابات الفرعية).
- `description`: وصف إضافي للحساب.
- `is_active`: حالة الحساب (فعال/غير فعال).

### **الاستجابة المتوقعة (`Response`)**
#### **نجاح**
</div><div dir="ltr">

```json
{
  "id": "acc-12345",
  "account_name": "البنك الرئيسي",
  "account_code": "1001",
  "account_type": "Asset",
  "currency": "SAR",
  "status": "created"
}
```

</div><div dir="rtl">

#### **أخطاء محتملة**
| **رمز الخطأ** | **السبب** |
|--------------|----------|
| `400 Bad Request` | البيانات غير مكتملة أو تحتوي على أخطاء. |
| `409 Conflict` | كود الحساب مستخدم مسبقًا. |
| `500 Internal Server Error` | خطأ غير متوقع داخل النظام. |

## **2. الحصول على قائمة الحسابات المالية**

</div><div dir="ltr">

### **Endpoint Details**
- **URL**: `/api/accountant/accounts`
- **Method**: `GET`
- **Auth Required**: ✅ نعم
- **Permissions Required**: `view_accounts`

</div><div dir="rtl">

### **وصف العملية**
يتم استدعاء هذا الـ API لاسترجاع جميع الحسابات المالية المسجلة في النظام.

### **الاستجابة (`Response`)**

</div><div dir="ltr">

```json
[
  {
    "id": "acc-12345",
    "account_name": "البنك الرئيسي",
    "account_code": "1001",
    "account_type": "Asset",
    "currency": "SAR",
    "status": "active"
  },
  {
    "id": "acc-67890",
    "account_name": "الموردين",
    "account_code": "2001",
    "account_type": "Liability",
    "currency": "SAR",
    "status": "active"
  }
]
```

</div><div dir="rtl">

#### **أخطاء محتملة**
| **رمز الخطأ** | **السبب** |
|--------------|----------|
| `401 Unauthorized` | المستخدم غير مصرح له بالوصول لهذه البيانات. |
| `500 Internal Server Error` | خطأ داخلي في قاعدة البيانات أو الخادم. |

---

## **3. حذف حساب مالي**

</div><div dir="ltr">

### **Endpoint Details**
- **URL**: `/api/accountant/accounts/{id}`
- **Method**: `DELETE`
- **Auth Required**: ✅ نعم
- **Permissions Required**: `delete_account`


### **وصف العملية**
يتم استخدام هذا الـ API لحذف حساب مالي من النظام. لا يمكن حذف الحسابات المرتبطة بقيود أو معاملات مالية.

### **الاستجابة (`Response`)**
#### **نجاح**

</div><div dir="ltr">

```json
{
  "message": "Account deleted successfully."
}
```

</div><div dir="rtl">

#### **أخطاء محتملة**
| **رمز الخطأ** | **السبب** |
|--------------|----------|
| `400 Bad Request` | الحساب مرتبط بقيود مالية ولا يمكن حذفه. |
| `404 Not Found` | الحساب غير موجود. |
| `500 Internal Server Error` | مشكلة داخلية بالنظام. |

---

### **البيانات التي يتم الاحتفاظ بها في قاعدة البيانات**
| **الحقل**         | **الوصف** |
|------------------|----------|
| `id`            | معرّف فريد للحساب المالي |
| `account_name`  | اسم الحساب المالي |
| `account_code`  | كود الحساب (يجب أن يكون فريدًا) |
| `account_type`  | نوع الحساب (أصل، خصم، إيراد، مصروف، حقوق ملكية) |
| `currency`      | العملة المستخدمة في الحساب |
| `parent_account` | الحساب الرئيسي التابع له (إن وجد) |
| `description`   | وصف إضافي للحساب |
| `is_active`     | حالة الحساب (فعال أو غير فعال) |

---

### **الملحوظات**
1. جميع الحسابات يجب أن تكون مرقمة وفقًا لهيكل محاسبي موحد.
2. الحسابات المرتبطة بالمعاملات المالية لا يمكن حذفها، بل يتم تعطيلها فقط.
3. يمكن للـ `account_type` أن يحدد الهيكلة العامة للحسابات المالية داخل الشركة.
4. يتم تكامل هذه الخدمة مع خدمات أخرى مثل `api_money_transactions_service` و `api_invoice_service` لإجراء العمليات المالية بكفاءة.
